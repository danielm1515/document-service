# מסמכי הדגמה

בתיקייה `demo/2026/` שישה קבצי PDF, זהים בתוכנם לשישה המקוריים של הבעלים (מ-2024), אך עם תאריך
הפקה מעודכן — **15.09.2026** — כדי שלא ייחשבו פגי-תוקף בהדגמה. הקבצים המקוריים (2024) פגי-תוקף
תמיד, לפי כל אחד מכללי התוקף (§2 בעיצוב), ומשמשים לבדיקה שהמערכת אכן מזהה זאת (`DOCUMENT_EXPIRED`).

## הקבצים ומה מצופה מהם בשירות המסמכים

| קובץ ב-`demo/2026/` | סוג מסמך | תוצאה צפויה עם תאריך 2026 |
|---|---|---|
| `01_ספירת_דם_מלאה.pdf` | `CBC` | `ACCEPTED` |
| `02_בדיקות_קרישה.pdf` | `COAGULATION_TESTS` | `ACCEPTED` |
| `03_תרשים_לב.pdf` | `ECG` | `ACCEPTED` |
| `04_בדיקת_שתן_לא_רלוונטית.pdf` | `URINALYSIS` | `ACCEPTED` — אך לא נדרש על ידי התור לדוגמה (`APT-8391`), שדורש רק `CBC`, `COAGULATION_TESTS`, `ECG` |
| `05_סיכום_טרום_ניתוח.pdf` | `PREOP_SUMMARY` | `ACCEPTED` — סוג משלו, לעולם לא מחליף `CBC`/`COAGULATION_TESTS`/`ECG` |
| `06_מסמך_לא_רפואי_חשבון_חשמל.pdf` | אינו סוג בקטלוג | `NON_MEDICAL_DOCUMENT` |

הקבצים המתאימים בשמות אנגליים (`cbc.pdf`, `coagulation.pdf`, `ecg.pdf`, `urinalysis.pdf`,
`preop_summary.pdf`, `electricity_bill.pdf`) נמצאים גם ב-`tests/fixtures/2026/` (ומקביליהם
המקוריים מ-2024 ב-`tests/fixtures/2024/`) לשימוש הבדיקות האוטומטיות.

## שימוש בהדגמה

יש להעלות את שישה הקבצים מתוך `demo/2026/` (השמות בעברית, כפי שמופיעים שם) בעת ההדגמה החיה.

## יצירה מחדש עם תאריך אחר

הסקריפט `demo/make_demo_pdfs.py` (Python של המארח, ספרייה סטנדרטית בלבד, מריץ את Chrome המותקן
במצב headless) מייצר את הקבצים מחדש:

```
python demo/make_demo_pdfs.py                        # 15.09.2026 -> demo/2026 ו-tests/fixtures/2026
python demo/make_demo_pdfs.py 01.12.2026 demo/december  # תאריך ותיקיית יעד אחרים
```
